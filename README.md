# 📋 Clipboard Manager

A desktop Clipboard Manager built with Python that stores clipboard history and allows users to quickly reuse copied text.

## 🚀 Features

- 📋 Save current clipboard
- 📄 View clipboard history
- 📌 Copy saved items back
- 🗑 Delete clipboard entries
- 💾 Persistent JSON storage
- 🖥️ Simple Tkinter GUI

## 🛠️ Technologies

- Python
- Tkinter
- Pyperclip
- JSON

```bash
pip install -r requirements.txt
```

```bash
python main.py
```
